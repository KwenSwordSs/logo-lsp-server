# Tests

This directory contains tests for the LOGO LSP server.

The tests are intended to validate the behavior of the parser, analysis components, and language-server features.

Covered areas may include:

- lexical analysis and tokenization
- parsing of LOGO source files
- procedure declaration detection
- variable reference resolution
- go-to-declaration functionality
- diagnostics and syntax error handling
- edge cases and malformed input

The goal of the tests is to ensure consistent and predictable language-server behavior across different LOGO programs.
